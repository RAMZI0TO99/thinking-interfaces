# P2Q revision4 qualification successor

New Q-only runner, independently reviewed and admitted before use. Preserves
Q4/P1Q clocks, native ownership, guards, pipe bounds and fault/timestamp probes.
Adds the P2 paged physical map, bounded PE parser and P admission-chain tests.
The planned suite has191 methods; source counts are not executed results.

Seven new methods test fresh ancestry/leaf predicates after lexical cache hits
and final-verification refusal after provisional preparation membership/absence
changes. The191-method roster and new P4 qualification join need fresh review
and admission; P3's deadline failure and unproved closure are preserved.

The30 reader methods target the new P2r3 reader, alongside eight explicit
long-path methods. Q bootstrap/control I/O retains the short Q2 reader. The
child final fixture census transports canonical paths locally through the
extended API spelling; no os/Path monkeypatch or Windows registry change is
used. Fixture audit allowances remain confined to the same admitted root.

The caller retains fresh compiler/reference pins, emits the P native helper
into memory, publishes a create-new PE using the original handle, loads those
exact readback bytes and queries/closes an empty P Job. P later loads that exact
qualified artifact without compilation. Q itself retains512/768 MiB caps and
60-second work/90-second whole limits. No package/candidate or numerical work.

See the implementation-specific P2 dependency contract. Source and actual
reviewers are different; every operation requires its own unused admission.
Old Q/P1 sources and receipts are frozen and never replayed.
