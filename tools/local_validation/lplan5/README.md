# Finite L inventory subset

This package is source only and has not been qualified or admitted. It parses
only supplied retained bytes, publishes occurrence inventories and diagnostics,
and always reports `INCOMPLETE_REFUSED`. It does not authorize collection or
imports. Callers must independently bind the exact five candidate-v2 modules,
physical pins, retained reader, shared output budget and migration record. The
inventory never establishes effect, binding, closure, exclusion, guard or ABI
proofs. Epoch and scope annotations are deliberately conservative; unknown is
not permission. Source encoding is restricted to UTF-8 (including BOM) or ASCII.
Limits and output budgets are validated before parsing. Page exhaustion refuses
and any previously written pages are incomplete orphan artifacts, not a result.

FQ obligations for the complete compiler, independently reviewed decisions,
Lhost compatibility, fresh Q/P, full 40-scenario qualification and accepted
plan remain outstanding. No L or validation case is executed by this package.

The LP8 consumer binds the exact five v2 module names, absolute paths, phases and
physical pins to the comparison record. It independently joins both roster
Refs to trusted descriptors, reads the relative comparison inputs using its
explicit project root and invokes `validate_migration` before this publisher.
The publisher merely records `migration_ref`; it neither reads that Ref nor
claims migration validation. Each checkpoint callback must return literal True.
