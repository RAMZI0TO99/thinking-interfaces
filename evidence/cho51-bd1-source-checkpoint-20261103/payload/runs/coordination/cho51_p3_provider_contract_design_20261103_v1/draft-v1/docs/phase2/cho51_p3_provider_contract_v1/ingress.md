# Original ingress, lifecycle and refusal evidence

## Two different layers

The frozen CM5/CM6/CM6S model's counters, events, seal and terminal are supplied-data contracts. PC1 adds a proposed **projection** of original outside-child observations. It neither changes that model nor supplies the missing original dispatcher. Inner negative fixtures retain their own operation/context/ordinal domains and may be expected PASS assertions in outer S140.

Every original ingress route must be enumerated before admission: dispatch entry, callback/reentry, native/transport queue, delayed work, retained callable/handle and any alternate writer path. The finite domain must include normal, rejected, late, nested and faulted calls, plus secondary refusal failure. An unenumerated route, unknown reachable allocation or unbounded work source is a pre-effect refusal. The existing supplied two-inflight bound and uint16 counters are not proof that native adversaries obey them.

## Linearization and state contract for a future observer

| Transition | Required original observation | Failure/effect mapping |
| --- | --- | --- |
| UNBOUND -> BOUND | Accepted retained authority, guard/T0 and unused O before any target effect | Missing basis refuses unadmitted; possible prior effects consume O |
| BOUND -> OPEN | Exact entry routes and source/code/type owners enabled under guard | Partial enablement records owned prefix and revokes every route already enabled |
| OPEN -> ENTER | One original attempt identity and invocation nesting/order recorded before target use | No allocation/dispatch before bounded admission; malformed, capacity, stop or stale authority refusal is distinct |
| ENTER -> SETTLE | Commit or refusal outcome for the same admitted invocation, exact observable effects and no synthetic replacement | First fault latches; refusal-helper failure retains incomplete prefix rather than forged complete refusal |
| OPEN -> REVOKED | Independent revocation of every route; exact cutoff ordinal | A producer boolean or leaked route cannot establish revocation |
| REVOKED -> DRAINED | All earlier admitted work settled, no owned in-flight execution; late/reentrant attempts independently accounted | Timeout/unknown worker remains incomplete with owned cleanup; no new T0 |
| DRAINED -> FROZEN | Immutable retained raw events, final refusal latch and actual suite/cleanup observations | Missing footer/cleanup/failed flush is incomplete; no repair or synthetic tail |
| FROZEN -> TERMINAL | External observer publishes the existing terminal role with exact raw and constructor pins | Publishing does not establish its writer's subsequent closure |

These are proposed original observation states, not new callable runtime code or a claim that an atomic primitive is available. Precise synchronization, memory-order semantics and all original sources of attempts remain native implementation/qualification obligations. At cutoff, any admitted-but-unsettled work remains in-flight; no event rewrite may turn it into a refusal merely to make arithmetic close.

## Closed supplied ingress snapshot I

The exact field/type registry is in packing.json. A snapshot includes O, binding pin, state, cutoff ordinal, entered, committed, refused, pending, late, first fault category, event record count/raw pin and original witness reference. Counts are exact integers0..65535, booleans rejected as integers; record count<=4096. Arithmetic at the supplied snapshot level is entered=committed+refused+pending. Late is a disjoint count of invocations rejected after revocation and is NOT silently folded into entered or the frozen producer apply counter. This explicit projection domain is different from frozen model counters.

A projection join must not directly equate entered to a CM6S model count. It requires an independently expected, complete native invocation-to-model-apply map with exact disposition of every attempt, including routes which never enter the model, late calls and interrupted calls. The map has no currently proved population/byte bound or reserved standalone file. It belongs to the existing caller journal domain if a future closed schema and complete fit are established; otherwise the original join refuses. A map digest alone is insufficient.

FROZEN/TERMINAL snapshots require pending=0 and an event pin matching actual retained bytes, plus original revocation/drain/suite evidence. Supplied facts can check these equalities, not establish their truth. Source-level negative checks may produce CONSISTENT_SUPPLIED or REFUSED_SUPPLIED only, always non-authoritative. An accepted original negative result requires complete original evidence; an incomplete prefix cannot be relabeled complete just because fault is nonzero.

The snapshot cannot prove an unbounded future absence of attempts. Required observation ends at an independently defined original final boundary with every entry capability revoked/closed and late work accounted. Its ordinal domains, bounds and actual complete ledger must be independently established; overflow or inability to capture the whole population refuses before execution where foreseeable and consumes/refuses if reached after effects.

## Failure classes remain distinct

| Failure class | Required disposition |
| --- | --- |
| Missing independent basis, unknown effects/domain/packing/control membership | REFUSED_UNADMITTED; no effects or attempt reuse |
| Expected supplied negative fixture | Inner refusal remains inner; outer assertion may PASS |
| Original complete producer refusal with faithful raw trace and complete terminal/ownership | Negative original result only; independent actual review required |
| Nested/late ingress, counter overflow, CM5-S01/S02 or secondary failure | Retain real evidence and first fault; complete-negative only if original grammar/closure is complete |
| Stop, low RAM/disk, timeout or blocked native operation | Original bounded owned stop/cleanup; attempt consumed, no reset/retry |
| Missing sample, capture loss, partial output, ambiguous native owner or EOF | INCOMPLETE_REFUSED/UNKNOWN as applicable; hashes and exit0 do not repair |
| Publication collision, partial create/write, confirmation mismatch | Consume the applicable O/M transaction; preserve created bytes, no overwrite or extra slot |
| Failure of the final observer or lost terminal delivery | No accepted original closure; preserve known prefix and UNKNOWN where custody is not established |

All16 inherited effect boundaries and546 indexed bodies remain obligations; the other516 held bodies and all49 discovery modules keep their original scope. This projection design does not complete recursive effects, formatter/destructor failure paths, allocation liveness or worst-case time. It does not discharge any of702 held rows.
