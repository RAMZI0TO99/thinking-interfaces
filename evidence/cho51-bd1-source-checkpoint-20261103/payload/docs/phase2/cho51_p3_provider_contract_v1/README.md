# PC1: original provider and evidence contracts

This is a source-only design successor to the [whole-operation plan](../cho51_p3_whole_operation_v1/README.md). It specifies an independently adopted trust/driver basis, bounded supplied witness projections, original ingress/capture obligations and a fixed-slot feasibility decision. It implements no provider, driver, encoder, collector or test.

The design distinguishes three results:

- A compact projection can have a closed grammar and a conservative storage reservation.
- Only independently established original native observations can give that projection provenance.
- Complete population, raw capture, final ownership and whole-operation feasibility still need separate proofs. A fitting summary is not such a proof.

[Basis](basis.md), [ingress](ingress.md) and [capture](capture.md) define the obligations. [Packing](packing.json) specifies proposed witness fields, finite scalar domains and existing-role assignments; it copies all33 report reservations without transferring capacity. [Qualification](qualification.json) defines32 new design scenarios, all unimplemented and unqualified. [Debt](cohort-debt.json) preserves1062/49, Q360/S140 and all702 held rows, including46 CM6S methods outside both cohorts. [Readiness](readiness.json) pins the other seven files and lists the open gates.

The useful implementation successor is a **supplied-data PC1 projection parser, independent binding/join checks and refusal classifier**, plus test roster/budget updates. It must label all outputs non-authoritative and cannot dispatch, contact a host or write original evidence. Native B0/B1 implementation/adoption, complete ingress/sample/capture packing, exact control membership, the46-method qualification decision and whole-operation resource closure remain separate mandatory work. That implementation is a next-step proposal, not performed here.

No runtime admission, execution, qualification, P preparation, debt discharge or scientific acceptance is created. P stays disabled; full Q probe,117/V34 and science remain held. Frozen sources and receipts are unchanged.
