# Canonical metadata boundary v1

This separately versioned engineering unit is a read-only metadata preflight,
not a production worker, parent, restoration factory or execution capability.
Source implementation and source-enumerated tests are not executed validation.
Fresh reviewed sources, runtime pins, native admission, peer scheduling and
external closeout are required before running the tests.
The current test source enumerates133 cases across29 test definitions; this is
not a collection receipt or passing test count.

## API and external package

`CanonicalBoundaryRequest(payload_json, expected_sha256)` freezes exactly the
caller-supplied UTF-8 JSON bytes and requires their independent lowercase digest.
`request.payload` returns a defensive copy. Unknown request/pin/role keys,
duplicates, nonfinite JSON, Boolean numerical counts and altered budgets refuse.

`assess_metadata(request, *, full_route, adopted_route, input_pins)` requires real
`ChoFirstTrancheRoute`, `Cho51WorkerRoute`, `Cho51RouteContract`, `CasePlan`,
`TrialCatalog`, `ChoProfileAssets60Hz` and `ChoCaseInputPins` classes. It returns
only immutable `BoundaryAssessment`; `report` is a defensive copy and
`canonical_json` is finite metadata. No callback, lock or executable token is
returned. The module's top level uses only the standard library. Genuine
canonical imports inside assessment transitively import NumPy/Torch; importing
these dependencies is not a claim that numerical APIs ran. Guarded validation
must observe those dependencies and forbid models, arrays and production work.

The request schema is `cho51_canonical_boundary_request_v1` with exactly:

- `root`: normalized absolute actual project root with genuine current Git.
- `execution_pins`, `metadata`: `{path,sha256}` project-relative metadata pins.
- `configuration`: exactly base/protocol/threshold/variant/ceiling/sweep/candidates
  at frozen `CONFIG_PATHS`/`CONFIG_SHA256`, plus one externally pinned cohort
  metadata-origin JSON. Unknown static settings cannot enter by self-pinning
  altered configuration bytes; changing these frozen templates needs a successor.
- `evidence`: exactly the six fixed path/hash accepted `ANCHORS` for direct owner
  adoption, unchanged proposal, original roster, accepted origin and both reviews.
- `roles`: producer/executor/recorder, each with exact `source` Git identity and
  `runtime_identity={role,evidence_sha256,fresh_runtime_verification_performed:false}`.
  Producer source comes from the authenticated historical origin; executor and
  current recorder use genuine current source. Their role-tagged evidence pins
  differ even when current source is shared. Historical recorder source remains
  separately labeled in the report. These are role-separated metadata identities,
  not new physical runtime qualification or flattened software-version strings.
- `prospective_numerical_budget`: exact source0/restore1/support1/gradient1/
  query-invocation1/query-trials2/model1/measured0 vector, never current activity.

`cho51_canonical_metadata_cohort_origin_v1`, `metadata_sha256`, the ordered
`available_subjects` roster and `raw_input_bytes_verified:false`. This digest
joins canonical input/execution pins without pretending an NPZ audit occurred.
The supplied typed routes must exactly match independent reconstruction of all
1040 original/1020 adopted identities, all52 catalogs/assets, all52 source-selection

Subjects02–52 are targets; all52 remain available sources. Only the prospective

All input-package reads are explicit JSON/TOML metadata; the exact reviewed
route-planner Python source is additionally authenticated, never compiled or

the exact currently loaded genuine helper module's contract class is accepted,
with pinned direct module/spec-origin paths and module/class identity retained
through assessment. Stale helper epochs fail closed after another context load;

Copied methods or accessor-bearing shadow classes are not genuine classes.
Before comparing, hashing or serializing any supplied typed graph, assessment
recursively checks exact approved genuine dataclass classes and plain primitive/

and containers. Slot values are read through genuine C member descriptors,
not caller accessors. Shared full/adopted-route references remain shared in
the defensive snapshot; later caller mutation cannot inject callback values.
String/integer/container subclasses, non-string dictionary keys and arbitrary
objects refuse without invoking their equality, hash, conversion or iteration.

referent without requesting collection or invoking mapping APIs. Only an exact
dictionary backing is admitted; custom mappings and dictionary subclasses fail
closed before proxy iteration. Built-in dictionary iteration validates each key
and value before constructing the owned copy. Typed-graph limits are500000 nodes,
depth40,32MiB aggregate UTF-8 text and64-bit plain integers; cycles refuse.
The fixture uses the genuine metadata-only `from_verified_full_route` helper,

## Deliberate hard boundaries

Positive status means only `metadata_contract_compatible`. Every authority flag
is false and every current numerical ledger entry is an exact integer0. Raw
inputs, weights, tensors, runtime, compute, unchanged canonical parent/worker,
single-root factory, measured publication and science remain unqualified.
No output tree, claim, recorder lock, physical source-selection procedure,
backend, model, decoder, source/support update, query, publication or recovery
is performed. The canonical metadata-only `source_selection` helper genuinely
reconstructs52 partition records; `physical_source_selection_performed:false`
does not deny that permitted metadata derivation. The old
canonical measured1 terminal is not intercepted or relabeled measured0.
Reports remain in memory; only a separately supervised custodian may persist
their bytes after independent validation. Reconstructing a report with a true
authority flag refuses, and even a forged metadata report is no execution token.

The test fixture writes only into the guarded pytest `--basetemp` inside the
actual project. It uses genuine current source/configuration/Git, real canonical
types and fabricated signal metadata explicitly labeled unverified. No fixture
NPZ, weight or model is created or read. Negative tests pass a genuine baseline
first; physical-race tests patch file I/O only, never source capture, Git or type
identity. Additional guard-level observation must independently enforce the
zero-side-effect contract, imports and sensitive-file refusals. No scientific
freeze signature, original target01 retry, accepted real case or study execution
is inferred from this package.
Reparse denial cases inject the leaf/ancestor attribute on a real stable file;
they test refusal branches, not a claim that an actual junction was provisioned
or a substitute for native direct-path admission checks.
