## 8. Phase II experiment contracts from the supplied plan

### E1 - pretraining-corpus trace / contamination probe

Primary design: inference-only masked-EEG-modelling loss and codebook usage
entropy on MMIDB against Cho2017, matched to 64 channels, 200 Hz, identical epoch
length and preprocessing. The unit of analysis is the recording. Use
subject-matched subsamples and save the sampling seeds. Include a randomly
initialized-weight control to separate exposure from generic signal difficulty.
Analyze the recording-level contrast with Mann-Whitney, an effect size and an
interval. State amplifier, reference and noise-floor confounds plainly.

MMIDB contributed 47.3 hours to reported LaBraM pretraining, so this is an
observational checkpoint probe, not the controlled intervention the authors ran.
Downstream dataset margins remain descriptive E1b evidence; do not claim a
confidence interval on a difference that has only one contaminated dataset.

### E2 - small-support adaptation

The scientific framing is conditioning/regularization in the small-support
regime, not parameter-efficiency for its own sake. Cho2017 is the primary dataset
for headline subject-level equivalence because it has 52 subjects; BCI IV 2a is
for fast iteration and a secondary four-class result. MMIDB is also in the matrix.

Declared dimensions: seven methods, shots 1/5/10/20, three datasets and five
seeds. If applied per target subject, this implies a large experiment, so the
plan requires a measured pilot and instance-hour estimate before launch. Every
record must include complete config, seed and commit identity. Failed fits remain
visible and may be relaunched only after their state is inspected.

Primary comparison: paired subject-level best parameter-efficient method versus
linear probing, with paired Wilcoxon and the frozen TOST. Report the paired
difference, interval, margin and achieved power. Failure to establish equivalence
is inconclusive; adaptation failing to beat linear probing is a valid headline
negative result.

The H2 margin is frozen at +/-0.0520290793 balanced-accuracy units
(+/-5.20290793 pp), alpha 0.05. Do not widen it after seeing results.

### E3 - causal window-duration and interface frontier

The existing committed design is `configs/e3_windows.toml`: Profile A windows
0.5, 1, 2 and 4 seconds, 0.25-second stride, causal query-only evaluation.
Metrics are balanced accuracy, latency, ITR, coverage and calibration. Dry-run
on EEGNet, then repeat under the real encoder latency profile. Tune the
accumulated-evidence analysis against measured accuracy, not assumed accuracy.
Benchmark the demonstrator on laptop CPU; it must run without GPU.

Do not confuse `configs/live_demo.toml` (4-second windows and 4-second stride for
the Phase I rehearsal) with the E3 sweep.

### E4 - montage retention

Prepare full, 32, 16, eight sensorimotor, eight random per seed and three-minimal
configurations. Mask electrodes by canonical name and test that dropping C3 by
name actually removes C3. The primary 64-channel sweep is Cho2017 and MMIDB.
Random eight-electrode controls must be resampled per seed, never one fixed
arbitrary montage. The Week 12 four-class BCI IV 2a result is secondary and only
if higher-priority work has not slipped.

Interpretability depends on the electrode-shuffle control: permuting identity
before spatial-embedding lookup must degrade performance substantially. If it
does not, stop; montage results are not interpretable.

## 11. Scientific and implementation cautions

- The Phase I seven-method benchmark jointly fits source and target support. It
  is not the same protocol as the separate support-only adaptation baseline or
  future E2. Do not reuse or mix those scores as E2 outcomes.
- Cho2017's loader concatenates class arrays. "Earliest" means available
  within-class order, not proven original acquisition chronology.
- Profile A/B differences are already fully reconstructed for A01. Units,
  reference, baseline correction, effective kernel duration and filtering all
  differ; do not repeat or reinterpret the 31.25-pp gap without a discrepancy.
- Artifact thresholds are frozen and label-blind. Do not retune them for Phase II
  outcomes.
- MMIDB pretraining overlap must be disclosed in every pretrained-encoder claim.
- The safe LaBraM checkpoint has 5,819,936 retained parameters, not the plan's
  5,822,770. Do not add parameters to force equality.
- The 800-sample configuration crops temporal embeddings and has 5,817,736
  backbone parameters plus a local classifier. Keep counts explicit.
- The generic LoRA wrapper cannot adapt LaBraM QKV as currently called. Merely
  exposing base weights would bypass the LoRA update and is not a fix.
- The prompt stand-in uses label embeddings, GELU and four prompts. Published
  TCPL specifies no support-label embedding, a ReLU MLP and ten 64-dimensional
  prompts with a specific TCN/Transformer. Keep identities separate.
- BatchNorm buffers and dropout behavior can change even when parameters are
  frozen. Compare full state dictionaries and declare the normalization policy.
- Query labels are evaluation-only. They cannot choose depth, early stopping,
  normalization, thresholds, prompts or support updates.
- Subjects are the inferential unit. Trials and repeated seeds are not independent
  subject replicates.
- A failed TOST is inconclusive, not proof of inequality. Report achieved power
  and the interval regardless of significance.
- Keep float days as buffer. Do not hide schedule slippage by silently consuming
  them or dropping failed runs.
