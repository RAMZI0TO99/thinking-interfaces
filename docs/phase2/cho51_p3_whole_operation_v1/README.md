Source-only design, 3 November 2026. This package turns the accepted S140
supplied contracts into explicit obligations for a future original operation.
It implements no runner, invokes no method and grants no admission. P stays
disabled. Source, supplied-model consistency, runtime qualification and accepted
scientific cases remain distinct claims.

  responsibilities, failure dispositions and the finite qualification path.

  lifetimes, pre-refusal allocations, missing bounds and unchanged guards.
- [Feasibility decision](feasibility.md): proved representation arithmetic,
  conditional workload, explicit unknowns and the admission predicate.

- [Readiness](readiness.json): exact source pins and unresolved gates.

The [accepted implementation](../cho51_p3_cm6_supplement_implementation_20261103.md)
and every predecessor remain frozen. None of the historical Q/P/QD evidence is
recertified for this operation. The existing source census, cohort manifests,
debt kinds/pins and failure/custody history do not change. No new test is added.

complete operation that has been shown to fit the original time/memory/capture
