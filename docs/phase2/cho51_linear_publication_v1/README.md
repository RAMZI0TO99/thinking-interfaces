# Two-root linear source publication and staged restoration

The accepted complete linear evidence binds a synthetic fixture containing
exactly five TOMLs. Its architecture recipe comes from the real project, where
the audited safe baseline is pinned. This new bridge states both roots
explicitly. It never rewrites the accepted evidence, adds baseline declarations
to the original fixture, or claims success for the unchanged single-root Cho
publication/restoration factory.

`publish_source(output, stage_contract, set_protected_inputs=callback)` creates
only an exact five-TOML metadata mirror under `publication_001/project`.
`capture_source(mirror)` must equal the accepted evidence's full source claim,
including fingerprint, Git revision and dirty state, before and after each
boundary. The original 213 synthetic inputs are reused read-only and rehashed;
no arrays or baseline files are copied into the mirror. The canonical default
store remains `mirror/runs/phase2/selected_sources`.
Each copied TOML is marked read-only before its source context is verified.

The real project independently supplies `prepare_cho_source_restore` and the
unchanged canonical `_new_model` lineage constructor. The actual pinned full
checkpoint is bounded to 64 MiB, safely decoded and strictly loaded into the
full 12-block/embed-200 LaBraM classifier. All 223 finite CPU float32 tensors,
5,818,138 elements and the fitted-state digest must match; only the 402 head
parameters are trainable, and the frozen backbone remains unchanged.

Publication retains canonical architecture-family, selected-adapter, method,
runtime and complete-evidence checks. The unchanged public
`SelectedSourceStore.publish` writes `full_v1` weights and canonical evidence,
then publishes its immutable manifest. The unchanged manifest-byte bridge binds
the actual files. Its generic 4 GiB weight-hashing ceiling remains unchanged;
the stage independently checks the exact weight identity and a 64 MiB bound
before and after that bridge. New CAS bytes may differ from the historical
checkpoint encoding while representing the identical tensor state.

`verify_publication(output, stage_contract, publication_result,
expected_publication_result_sha256=pin, set_protected_inputs=callback)` requires
an external physical pin for the accepted publication result. A separate fresh
Job performs two new staged restorations. The first releases a digest witness
without an adapter; the second factory releases the real `LaBraMTunedAdapter`.
Each independently rebuilds the baseline and calls unchanged public
`SelectedSourceStore.restore` with an explicit 64 MiB maximum, then repeats the
complete-evidence, method, runtime, baseline and source checks. All 223 tensors
must match exactly across the two fresh models, with disjoint storage.
The named `_staged_digest_check` returns its private model and digest witness,
with no adapter. `_staged_adapter_factory` returns the actual model, concrete
tuned adapter and witness after all release checks; these new entry points use
the authenticated two-root bridge context and native protected-input scope.

Both Jobs retain canonical 6/4 GiB host-RAM checks and native limits of 600
seconds, 4,096 MiB process, 5,120 MiB Job, 10 GiB startup RAM, 4 GiB active RAM,
20 GiB disk, one Torch intraop/interop thread and hidden GPUs. The publication
performs three safe decodes, two strict state loads and one safe save. Detached
verification performs four safe decodes, four strict loads and no save. Neither
Job creates an optimizer, fits, predicts, reads protected outer-target content
or consumes an original-case attempt. Global Torch, NumPy and Python RNG states
and all original inputs must remain unchanged.
The upstream constructor's no-gradient zero-tensor patch-shape probe is allowed
only inside that exact constructor subtree. Data and classifier inference stay
blocked; this constructor probe does not consume a subject or produce a result.

Ordinary JSON proofs are bounded to 8 MiB; the exact complete selection evidence
has a separate 32 MiB limit. Results contain compact physical/logical pins and
summaries. Safe weights and original arrays are excluded from compact evidence
archives. Publication and restoration qualify this explicit staged bridge only.
Recorder integration, full worker qualification, earlier pretrained cohort proof,
owner freeze and scientific admission remain pending.
