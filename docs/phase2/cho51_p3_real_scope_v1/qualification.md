## Ordered gates

1. Implement only the fixed supplied-byte probe, its closed selector/report and
   refusal path in a new version. Retain the complete accepted kernel/codec and
   all484 inherited method identities. P operational entry points continue to
   refuse. No real-source traversal service, aggregate reconciliation, automatic
   module loop, commit index, continuation adapter or P consumer is in scope.
2. Freeze exact schemas, bounded encoders/guards and the complete operation
   allocation. The current256-source ceiling is full: use reviewed counterpart
   version replacements, including every live dependency; no omission or hidden
   new import to meet the count. Source pins may never exclude a new helper.
   Raw probe assets are declared data, never silently loaded by candidate import.
3. Independent source review checks conservation, scope rejection and all
   scenarios below. Freeze an exact method roster with32 new methods and484
   inherited identities (516 distinct if implemented one-to-one), provisionally
   partitioned384 and132. No cohort exceeds384. If source review requires a
   different finite partition, pin it before admission and retain all identities;
   partitioning tests is not partitioning the project's continued state.
4. Root records fresh Q admission per cohort after current resource/stop checks.
   Each cohort runs eight UTC, two actual native faults, three sharing, five
   observer and two bootstrap controls. Sharing is already in the384 inherited
   methods and runs separately for other cohorts; do not inflate distinct counts.
   Exact source/runtime pins must match across the aggregate. No timing guarantee,
   automatic retry or resource relaxation follows from the design.
5. A distinct actual reviewer checks saved exact roster/control results, original
   caller/process/Job/streams, retained inputs, final verification, cleanup,
   allocation and bounded real-source observation. Static copied bytes prove no
   native origin: distinguish a supplied real-source fixture from an independently
   admitted current-path read. The first probe is a supplied fixture with exact
   reviewed bytes; it cannot report fresh custody at the original package path.
6. Root may accept only the Q mechanisms and that named observation's actual
   scope. P remains disabled. Global reconciliation, G2, loader/ABI, candidate117,
   V34 and science remain pending. Successful probe qualification does not
   authorize a sweep of other modules or discharge any obligation.

Source review and actual review require different peers, neither an implementation
author. Current design acceptance is yet a third claim and runs no tests.
