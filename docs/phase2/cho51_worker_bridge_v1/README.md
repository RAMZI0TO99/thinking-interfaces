# Adopted51 actual worker/input bridge

This separate wrapper implements the [adopted target scope](../cho_51_target_amendment_adoption_20261013.md)
over the unchanged real 52-subject input loader. `worker_bridge.py` uses the
actual `CasePlan`, `TrialCatalog`, `ChoCaseInputs` and `ChoFirstTrancheRoute`
classes. It retains all 52 source catalogs/assets while exposing only the
1,020 adopted plans. Subject01 evaluation inputs, wrong seeds/shots/repetition
and untyped plans are refused before delegation. Subject01 remains a source.

`prepare_cho51_worker_route` reuses the original input-byte verification and
then binds the exact owner decision, retained IDs and method digests through
the versioned metadata planner. That planner's isolated AST loader is not
called: the bridge supplies the real worker classes. `from_verified_full_route`
assumes independently verified real input bytes and checks the complete original
plan, worker types, retained subset and all52 assets. It does not independently
authenticate an arbitrary caller's source route or grant scientific admission.

[Fresh qualification](../cho51_worker_bridge_qualification_20261013.md) passed
15 tests: actual types and all1,020 input/profile assignments, all52 real A
catalogs and B artifact/manifest pairs, all51 target episode records, source
folds, refusal boundaries and a real subject02 five-shot 60Hz binding. Its
10 support and159 query epochs have64 channels and800 samples. The binding
hash matches the retained cohort audit. Other targets' B array joins remain
unqualified by this step; their asset hashes and episode records were checked.

The original validator and failed guard are preserved. `validate_bridge_002.py`
normalizes the Windows extended local-drive prefix before audit comparisons,
keeping the exact same157 allowed data paths. It blocks other raw files,
checkpoints, network/DNS/subprocesses and outside writes. Model and recorder
construction/checkpoint loading are blocked in the test process. One local
hostname metadata query was allowed; no network operation occurred.

The existing1,040-case sweep and analysis collector require a separately
versioned integration. This wrapper is not a drop-in scientific experiment
launcher. Complete B array binding, fitted candidate selection, recorder/
collector and numerical worker/resource qualification, checkpoint-cohort review
and final owner freeze remain pending. Original attempts stay0; no reset follows.

On another Windows device use [WINDOWS_SETUP](../../../WINDOWS_SETUP.md), then
prepare fresh source/runtime/input pins, coordination and guarded admission.
The loader requires the declared whole-file input identities; archive-member
checks alone do not qualify a different ZIP byte stream for this bridge.
Conflicting input hashes must receive a reviewed lineage/input successor, never
overwrite the old audit or bypass its checks. Published recipes and guards are
dated evidence. `* -text` retains the candidate bytes exactly.
