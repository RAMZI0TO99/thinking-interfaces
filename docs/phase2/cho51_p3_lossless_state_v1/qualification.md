# Qualification and implementation boundary

This is an unexecuted design matrix. It extends the accepted FC01-FC32 and
RP01-RP24/FP01-FP12 obligations; it does not replace them or claim real-source
reconciliation. Root owns future integration/admission. One implementation author
may own a new codec/verifier package. A different source reviewer and a separate
actual-result reviewer must accept their respective evidence. Root plus one peer
remains the active team limit. No implementation is made in this design step.

The next implementation is pure supplied-byte/data code plus Q integration.
Suggested interfaces are `pack_supplied_chain(...)` and
`verify_supplied_bundle(...)`; exact signatures, fixed result/check enums, versioned
source ownership and consumer schemas must be frozen before source acceptance.
Only the trusted live checkpoint callback is an executable input. No input source
parser, dynamic import, file/network reader or writer, native custody claim, real
producer or P dispatch is included. The existing operational P refusal stays.

Map each design row to exact method IDs; split as needed and disclose unexercised
parts. Small synthetic witnesses can test capacity refusal without claiming to
have reconstructed the historical real graph. Native publication/crash/retained
handle/cleanup scenarios remain future host qualification under RP19/RP20/RP24;
an in-memory codec test cannot qualify native CreateNew or custody.

Fresh Q must retain384 inherited +40 resolver +32 frontier methods, then add the
new explicit method set. No cohort exceeds384 methods. Every cohort runs eight
UTC, two native faults, three sharing, five observer and two bootstrap controls;
the three sharing methods remain within the inherited384 and run separately
for other cohorts without becoming additional distinct method IDs. Exact source
and runtime pins must match across the reviewed aggregate, with unused operations
and independent actual reviews. Common sources remain <=256: review counterpart
consolidation rather than omitting live dependencies to fit. No historical Q
acceptance certifies changed code or this not-yet-implemented format.

Future real-source producer/P requires its own accepted feasible contract,
complete reconciliation and current coverage, matching reviewed callers, fresh
Q and separate P admission/actual review. Under the present unchanged guards,
the complete real case is refused by design. L, candidate117, V34, the original
qualification/custody matrices and science remain separate and unexecuted here.
