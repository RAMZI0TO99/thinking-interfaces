# Versioned 51-target route contract

The owner [directly adopted](../cho_51_target_amendment_adoption_20261013.md)
the exact retrospective amendment. This separate planner distinguishes the
52-subject available cohort from the 51 evaluation targets, subjects 02–52.
It leaves the existing 52-target implementation and all active configs intact.

`route_contract.py` binds the exact preserved owner decision and proposal,
checks all retained/excluded identities against the original roster, and
rederives all 1,020 case IDs. It executes an isolated AST of the pinned original
`CasePlan` class with the unchanged configuration digest; the complete runner,
Torch, model factories and recorder are never imported. This checks the class's
identity equations; full worker class interoperability remains unqualified.

The original pinned `TrialCatalog` and `source_selection` code constructs the
source graph from 52 explicitly supplied typed catalogs. Every outer target
has 51 sources, including subject01. Every inner validation fold has 50 training
subjects and excludes both outer target and validation subject. All 2,601 folds
are checked. Method digests, seeds, shots and repetition remain unchanged.
The produced route maps are immutable, and a summary rederives the whole route
before accepting it; partial or self-constructed changes are refused.

`validate_route.py` supplies fabricated catalog metadata and tests the scope,
identities, folds and refusals under a fresh guard. It reads no real arrays,
checkpoints or recorder state, imports no numerical/model libraries, and blocks
network, subprocesses and outside writes. The
[27-check qualification](../cho51_route_contract_qualification_20261013.md)
and [exact evidence](../../../evidence/cho51-adoption-route-20261013/README.md)
retain the direct decision and executed native receipts.

This is a metadata route contract. Production integration still needs the full
worker classes, pinned real Profile A/B catalogs and assets, target episodes,
selector and recorder/collector bindings, complete numerical worker/resource
qualification, checkpoint-cohort review and final owner freeze. The contract
does not create a runnable experiment or supply scientific execution authority.
The earlier 51-subject numerical candidate's receipts retain their dated scope.

For a Windows clone, use [WINDOWS_SETUP](../../../WINDOWS_SETUP.md), then establish
fresh pins, runtime review, coordination and finite admission. Recorded launchers,
paths and guards are inert. `* -text` preserves all route candidate bytes.
