# Cho synthetic report publication candidate

This candidate fills the report-format and write-once publication gap using
only five internally generated fixtures. It accepts no scores, cell directory,
recorder, checkpoint, training inventory or scientific admission. It uses the
unchanged exact-rational aggregation and proposed paired calculation modules.
Every report is marked `synthetic_engineering_only`; all scientific, freeze,
cohort and execution authorization flags remain false and original attempts
remain zero. A numeric condition on invented values is never a scientific claim.

The 1,040 fabricated cells become 208 five-seed means and 52 subject pairs.
The JSON retains every rational score, mean and paired difference, exact tie
levels, unrounded p-value, separate 95% and 90% paired-mean intervals, the
unsigned owner proposal and implementation/context hashes. The Markdown preview
shows the exact subject pairs. Full tuning and EEGNet have descriptive means;
there are no secondary p-values or formal equivalence decision.

`synthetic_report.py --project-root ROOT --context-file FILE --output-directory
NEW_DIRECTORY --fixture zero|positive|negative|ties|rank_mean_disagree`
creates `report.json`, `preview.md`, then `receipt.json`. The supplied context
records the execution Git, canonical source, quality pointer and unchanged
owner packet hashes. It is a declaration until an external guarded execution
review verifies it. The candidate independently checks the bytes of the six
project modules it imports and the owner packet before any calculation.

The destination must be new and have a regular, non-reparse parent chain.
Existing files/directories are never overwritten. The last receipt commits
both output hashes; an interrupted directory has no complete publication.
`verify_publication` requires the exact three-file inventory, regular files,
matching byte hashes and deterministic regeneration from the named internal
fixture. Self-consistent changes to authority flags are also refused. Hashes
do not authenticate an author, a real training cohort or a scientific result.

`validate_report.py` is the separate, bounded qualification recipe. It covers
exact subject units, ties/zeros, a small signed-rank p-value with a negative
arithmetic mean, write-once and interrupted publication, tampering and CLI
refusals. It imports NumPy/SciPy for synthetic numerical checks, caps native
threads at one, and records the actual loaded runtime files. It starts no
model, fitting, recorder or real-cell operation. This candidate is not the
production Phase II analysis command or an adopted executable configuration.
