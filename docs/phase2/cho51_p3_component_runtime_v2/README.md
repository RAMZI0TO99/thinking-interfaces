# CM2 retained loading and result production design

This source-only successor design leaves CM1 and all predecessors frozen. It
turns the 216-method navigation index into a direct-body effect and normal
callback inventory and specifies the remaining runtime boundary. It adds no
Python implementation, test identities, launch command, runtime pins or admission.
The roster stays 732 identities / 30 modules, with 216 selected; P stays disabled.

The [method inventory](method-effects.json) contains direct reviews of all 216
selected bodies and named local helpers. It counts 210 normal successful subtest
callbacks. With one start, PASS and end per selected case, the proposed normal
event shape has 860 records including header/footer, at most 440,320 bytes at
the unchanged 512-byte record cap. This is conditional source arithmetic, not
executed tests or a complete failure/capture bound.

[Phase edges](phase-edges.json) preserve 72 project-module skeleton entries and
14 package parents, direct textual imports, concrete unresolved edges and the
separate discovery/execution phases. They are not a runtime allowlist.
[Loader](loader.md) and [result production](results.md) specify retained byte,
object, fixture, callback and final aggregation requirements. [Feasibility](feasibility.md)
separates the new normal event result from remaining failure, capture, native,
allocation and timing obstructions. [Readiness](readiness.json) and
[qualification scenarios](qualification.json) define the next source gate.

Root and cm2_effect_inventory authored the analysis; cm2_loader_trace supplied
read-only code trace. Independent design acceptance is recorded outside this
directory. No source reviewer authored these design files. The next bounded
implementation may add only the reviewed supplied retained-byte/code-table and
callback-state adapters with default refusal. A real importer, collector or
producer remains held until exact runtime closure and finite failure/effect
proofs exist; no import or collection is a source-only preflight.
