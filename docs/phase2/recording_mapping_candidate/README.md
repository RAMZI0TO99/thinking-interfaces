# Raw-recording filename mapping candidate

This separately owned candidate relates stored project groups to filenames
using pinned loader rules. It is not proof that existing cached signal arrays
were processed from those exact bytes. It hashes 18 BCI MAT and 327 MMIDB EDF
files without decoding signals or annotations; 52 Cho hashes retain the dated
raw audit scope. Fixed public PhysioNet checksum metadata and the installed MNE
registry provide separate MMIDB raw-file integrity comparisons.

The candidate does not import or execute scientific loaders, retrain models,
decide checkpoint cohort overlap, sign scientific gates or freeze a query roster.
It requires a separately pinned, fresh, bounded guarded attempt. The helper
`metadata_reader.py` is copied unchanged from the independently qualified
[identity inventory candidate](../evaluation_identity_candidate/README.md).
Preparation alone is not executed qualification.
