[independent design review](../../runs/coordination/cho51_p3_real_scope_design_20261101_v1/design-review-v1.json)

## Useful bounded scope

The probe will compare syntax occurrences from one complete pinned source with
explicit historical row identities. It may establish field/path/span agreement
for those bytes; it cannot approve effects, bindings, ancestry, package contents,
transitive dependencies, native custody or G2. It produces no checkpoint, cursor,
continued state or exhaustive reconciliation. Reports cannot be combined into
a state that resets the project's aggregate/history limits.

The [static case](../../runs/coordination/cho51_p3_real_scope_design_20261101_v1/static-case.json)
selects `packaging/__init__.py`, 494 bytes, whose current hash matches the retained
source pin. It retains the whole historical page54 (256 rows, 160,029 bytes), the
whole index (39,086 bytes) and exactly rows176–213: one origin and 37 syntax nodes.
The selected ten effect annotations and one unresolved binding load remain open.
All 218 other rows in the copied page remain intact and outside the comparison.

The raw assets total 199,609 bytes. The proposed six-file output has a conservative
498,123-byte bound, including selector, full bounded report and receipt. This
establishes **STATIC_DATA_ENVELOPE_FITS_RUNTIME_UNQUALIFIED**. It does not establish
full-operation allocation, interpreter/native memory, timing, parser behavior,
fresh path custody or actual cleanup. Those remain explicit implementation,
source-review, admission and actual-review gates.

File/JSON/hash inspection rechecked the 136 inputs behind the earlier accepted
occurrence analysis. No source AST, codec, kernel, compiler, native helper, Q/P,
test or scientific operation ran. The real source was read as inert file data.
No package was imported and no Git operation was performed.

## Conservation and qualification

All 18,793 resolver rows and 13,406 separate inventory occurrences remain in
their unchanged complete historical bundles. The explicit selection leaves
18,755 resolver rows outside this comparison, while even the 38 selected rows
discharge zero obligations. All 724 queued contexts, 1,782 frontier records,
1,786 unresolved binding loads and 3,972 effects remain outstanding.
The full raw index in the probe does not certify unsupplied pages or replace
their payloads. The existing codec's complete-family checks stay unchanged.

The design defines closed request/result schemas, exact occurrence joins,
live-guard refusal, bounded traversal/encoding, immutable evidence and rejection
by checkpoint/P/plan consumers. It preserves all process/Job, time, memory, disk,
stop, retained-input, final-verification, cleanup and consumed-attempt controls.
The extra fixed-case bounds tighten the probe; they do not redefine the kernel's
logical-state denominator or grant another output budget.

There are 32 planned scenarios, all unimplemented and unexecuted. Implementation
must retain the 484 methods accepted by the
[codec milestone](cho51_p3_lossless_codec_implementation_20261101.md). A provisional
384+132 partition would contain 516 distinct methods, with every required control
in each fresh Q cohort. Exact source/runtime pins, complete allocation, source
review and independent actual review remain mandatory; the design promises no
timing guarantee or automatic retry.
