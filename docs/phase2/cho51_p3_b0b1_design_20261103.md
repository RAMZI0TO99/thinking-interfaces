# BD1: native provider, finite driver and qualification entry

3 November 2026. The eight-file [BD1 design](cho51_p3_b0b1_v1/README.md)
is independently accepted for design only. No implementation, build,
Python/import/parser/AST/compiler/native/test/Git/runtime execution occurred.
P remains disabled.

The design selects native G0 and S0, using fixed buffers and overlapped named-pipe
I/O under an independently adopted original external host H0. H0 must supply
guard, provenance, capture and final-writer observation independently of the
candidate it qualifies. The present assistant/tool session is not assumed to
provide that authority. Original Job attachment, inheritance, ownership,
cancellation completion, failure and refusal obligations remain explicit.

The proposed first entry is E1_PROTOCOL/NOMINAL_ECHO: one96-byte fixed request
and one80-byte normal response. It has no test child, Python, cohort discovery
or Q360/S140 selection. It is a distinct prerequisite scope, not a shortened
qualification run. Actual native entry remains **REFUSED_UNADMITTED**.

Resource observations use a proposed80-byte lossless record; capture/control
observations use64 bytes. The design accounts for original read populations,
EOF/error/cancel transitions, base64 and exactly specified JSON escaping.
Valid PC1 B/I/C field domains have688/684/833-byte canonical upper bounds,
conservatively reserved at1024, without changing their8192-byte input guards.

Six proposed existing-role regions fit arithmetically under the explicitly
bounded E1 source/transport domain. This is **conditional representation fit**.
It does not prove complete source/failure populations, wrapper compatibility,
manifest closure, peak memory or time. Arbitrary1MiB output still does not fit
the old escaped-return counterexample. All33 report reservations/18890752 bytes
and16 closeout roles/3293184 bytes remain exact; no slot or pooled capacity is added.

The final M write cannot prove its writer's subsequent closure or pin itself.
H0 must supply an independently retained original witness after the final charged
write, without a seventeenth report, hidden sidecar, extra clock or recursive
self-closure. **That actual retention/delivery route remains unestablished.**
Original O response and later M finalization stay distinct. Complete capture/
closure packing and whole-operation feasibility remain **NOT_ESTABLISHED**.

The source census is unchanged at **1125 identities/51 modules**, with fixed
**Q360/S140** and **765 exact held rows** (516 baseline+249 new unqualified).
No methods were added, promoted, reclassified or discharged. The40 BD1 design
scenarios are unimplemented/unqualified, alongside all original scenario debt.
Full Q,117/V34 and scientific work remain held; science is0/1020 and the freeze
unsigned. Historical consumed failures and UNKNOWN custody are preserved.
