## 1. Which source governs current work?

The [project execution policy](../PROJECT_EXECUTION_POLICY.md),
[current handoff](../../HANDOFF.md) and
[agent coordination rules](../../AGENT_COORDINATION.md) govern current
engineering work. Planning, source review, admission and result acceptance are
owned within this project. Older scheduling and approval arrangements in
historical records are not current prerequisites.

For scientific scope, use the exact owner decisions and their explicit
successor amendments. Historical source hashes bind the original sources or
archived snapshots, not intentionally advanced documentation heads. A receipt
cannot certify an unexecuted successor or another runtime.
